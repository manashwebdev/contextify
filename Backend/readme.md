# Contextify

AI-powered prompt optimization platform that transforms raw user context into structured, role-based prompts.

## Features

- AI Prompt Generation
- Multiple Prompt Types
- Modern UI
- Gemini API Integration
- Copy Prompt Functionality

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Gemini API

## Setup

npm install
node server.js
